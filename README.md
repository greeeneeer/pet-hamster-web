# 쥐덩이 (웹 배포용)

털 달린 3D 햄스터를 쓰다듬고 잡아당기는 웹 장난감. 이 저장소는 GitHub Pages 배포용으로, 웹페이지 파일만 담고 있다.

- 바로 하기: https://greeeneeer.github.io/pet-hamster-web/
- 컴퓨터: 마우스를 올려 쓰다듬기 · 왼쪽 버튼으로 잡아당기기 · 오른쪽 드래그로 돌려보기 · 휠로 확대
- 휴대폰: 햄스터를 쓸어 쓰다듬기 · 길게 누른 뒤 끌어 잡아당기기 · 바깥을 끌어 돌려보기 · 두 손가락으로 확대

로컬에서 열 때는 `python3 -m http.server` 로 서버를 띄운 뒤 http://localhost:8000 을 연다. (three.js를 CDN에서 받으므로 인터넷 필요)
